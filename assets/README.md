# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Game of Life uses `fonts/life_font_16.c`: Noto Sans SC Medium (weight 500), 16px, 4bpp,
uncompressed, covering the code points recorded in `fonts/life_font_inventory.json`, including printable ASCII and the
complete fixed Chinese interface. `fonts/OFL.txt` retains the OFL-1.1 license.
The source is [Noto Sans SC Variable](https://github.com/notofonts/noto-cjk/raw/refs/heads/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf).
`fonts/life_font_inventory.json` records source/output SHA-256 values and all
code points; `fonts/life_font_codepoints.h` supplies the runtime lookup check.
The app has no external text input.

Select Node 22.22.3 through fnm, run `npm ci --prefix tools/font`, install
`tools/font/requirements.txt` in a Python virtual environment, then run
`python3 tools/generate_life_font.py --source <NotoSansSC-VF.ttf>` to generate
the linked source. The pinned converter is `lv_font_conv` 1.5.3, using
`--size 16 --bpp 4 --format lvgl --no-compress --no-prefilter`. FontTools 4.60.1
instances the variable source at weight 500 before conversion; `fonts/NOTICE.txt`
retains its copyright notice.
Run `python3 tools/generate_life_font.py --check` after changing UI text.
Native LVGL rendering and physical-device Chinese rendering are separate checks.

The phone companion uses `fonts/life_mobile.ttf`, mirrored into its Flutter asset
directory by `tools/generate_mobile_font.py`. It is the same licensed Noto Sans SC
source at weight 500, subset against the fixed Dart UI and recorded in
`fonts/life_mobile_inventory.json`. Generate it with the same Python environment
and `--source <NotoSansSC-VF.ttf>`; `--check` verifies coverage and both asset hashes.
External speech text uses normal platform font fallback rather than a claim that
the fixed UI subset covers arbitrary input.

Store reusable font files and generated font sources in `fonts/`.

The acoustic site uses `fonts/life_web.ttf`, mirrored to `site/public/fonts/` with
its OFL and copyright notices. `tools/generate_web_font.py --source <NotoSansSC-VF.ttf>`
subsets the same weight-500 source against the complete HTML and JavaScript UI.
`--check` validates coverage and both hashes against `fonts/life_web_inventory.json`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

## Images

`images/life-controller.svg` is the application's original glider icon (MIT).
`python3 tools/generate_mobile_icons.py` uses librsvg and ImageMagick to generate
the Android, iOS and web icon sizes from that vector; generated PNGs stay in their
platform asset directories.

Store reusable source images and generated display assets in `images/`.

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.
