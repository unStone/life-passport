# 手机种子编辑器

当前手机测试采用[浏览器声音实验室](acoustic-lab.zh_CN.md)，无需Android应用即可发送可复现key。保留Flutter原型源码供后续评估，下表描述该原型能力；设备端保留已验证的BLE接收能力，完整种子仍需实体按键确认。

## 行为

| 范围 | 约束 |
| --- | --- |
| 编辑 | 完整36×32棋盘，触摸绘制／擦除、撤销、预设、随机密度、预览和清空。 |
| 语音 | 手机语音识别及文字等价入口支持明确的预设／密度指令，不默认接入未配置的云端模型服务。 |
| 连接 | 仅发现生命游戏服务，申请平台权限，连接并订阅，提供断开入口；两个系统共用 BLE 协议。 |
| 传输 | 一次一个请求，按 BLE 写入确认显示进度；只有匹配的应用确认才能显示成功，错误、超时和断线明确呈现。 |
| 设备确认 | 有效种子暂停预览，确定键应用，长按确定取消并恢复原棋盘；手机保持连接时确认画面持续亮屏，确认或断开后恢复常规空闲电源管理。无效／不完整请求不改变棋盘。 |
| 独立使用 | 不连接手机也能运行，默认间隔200ms，输入处理独立进行。 |
| 交付 | 本轮交付设备固件；保留的手机原型不作为安装前提或已经选定的同步方式。 |

## 协议

BLE 使用生命游戏控制服务 `e13b0001-c18b-4a9f-8949-7e9aa6579220`，同一128位基址下 RX 为 `e13b0002-...`、带响应写入，通知为 `e13b0003-...`，只读状态为 `e13b0004-...`。读取与通知使用不同特征，避免 CoreBluetooth 共用值更新回调时混淆。广播名 `LifePassport`，不传账号、凭据或个人文本，每个种子需实体按键确认，游戏数据通道不用于私密数据。

请求为换行终止的 JSON，最多1023字节，包含 `v=1`、32位正整数 `id`、`op="seed"`、`w=36`、`h=32`、32个整数 `rows`、`crc`、`interval_ms` 和布尔值 `wrap`。第y行的第x位表示细胞(x,y)，每行小于2^36，JSON 数字能精确表示；CRC32 为 IEEE/zlib CRC，对行优先、低位在先的144字节棋盘计算。支持1000、500、200、125ms间隔。

不完整输入5秒超时，超长输入丢弃至下一个换行；cJSON 解析完整请求，校验尺寸、类型、整数边界及 CRC 后才交给应用任务。等待确认时拒绝新种子，相同编号／校验值重试返回当前确认结果，相同编号不同内容拒绝。

TX 通知为短标记 `changed`，调用方从独立状态特征读取完整 JSON，MTU 23 时使用 GATT 长读取。回复包含 `v`、匹配的 `id`、`ok`、`crc` 和 `state`（`processing`、`preview`、`applied`、`cancelled`）或错误，仅后三种状态属于应用确认。BLE 回调只解析有界输入并入队，状态由所有者任务修改并发布确认；LVGL 操作持有 BSP 锁。断开连接清除不完整输入，保留最后完整事务结果；正式 cJSON 解析器设置四层嵌套上限，限制外部输入的栈开销。

## 验证

先实现并测试编解码和状态流转，再实现 BLE，最后实现手机调用方。主机覆盖分片、异常 JSON、边界、校验、超时和预览／应用／取消；Flutter 覆盖模型／语音指令、分帧、确认编号和编辑交互。完成完整固件验证、Android/iOS 构建后，刷写确切合并镜像，观察启动、代数、界面耗时、堆和看门狗；真实手机权限、语音、配对、显示和休眠分别进行实物检查。
