# 网页种子图鉴

PC／手机编辑器提供Stephen Silver《Life Lexicon》第29版中的 **519个**完整具名图案。原始编辑者包括Dave Greene、David Bell，完整贡献者及CC-BY-SA-3.0声明保留于[NOTICE.txt](../assets/patterns/NOTICE.txt)，并附[许可全文](../assets/patterns/CC-BY-SA-3.0.txt)。应用代码继续采用MIT，派生图鉴数据保留CC-BY-SA-3.0。

在编辑器打开图鉴，搜索中文／英文名称或特征、筛选分类，再点击缩略图载入。载入对应一次撤销，可继续编辑、预览或声音发送；图鉴首次使用才加载，每页24个缩略图。数据、字体和解码器资源全部由当前网站提供，来源链接仅为可选外部参考。

## 来源与适配

已核对来源为[rokicki/lifecontent](https://github.com/rokicki/lifecontent/tree/19eeabbf84b94f6a53791774e4377e766e10c0c6)，固定提交 `19eeabbf84b94f6a53791774e4377e766e10c0c6`。单页词典SHA-256为 `0e828cf69196ef1a98936ebb40c8791dd9da049f76c4b37386e7dd7389c930c8`。使用BeautifulSoup／html5lib读取HTML，通过完整 `ca-formats` 0.3.5库解析真实图案坐标，不自行编写格式解析器。

生成器对每个具名词条取首个图案，仅在适配36×32时旋转整个图案，并完整居中，不裁剪细胞；去除旋转／镜像和周期相位重复。分类使用生产网页B3/S23模型，在实际36×32环绕棋盘上观察最多256代，描述的是有限观察，不保证无限空间行为。JSON保留原始尺寸、名称、来源段落与参考链接。

来源提取出682个具名图案，其中519个满足尺寸、独立性和演化筛选。[catalog.json](../assets/patterns/catalog.json)同步至 `site/public/patterns/`，每项保留精确144字节位图、细胞数、尺寸和CRC；网页校验后才提供选择，损坏文件不会静默替换为其他图鉴。

## 重建与验证

固定来源、依赖与命令见[图鉴工具](../tools/catalog/README.zh_CN.md)。普通构建使用已跟踪的数据，不需要Rust或联网下载词典。`npm test --prefix site`校验来源身份、分类计数、至少200个独立图案、至少200个非静物、对称唯一性、镜像文件字节，以及全部519项经过生产C声音接收器的精确往返。网页字库清单包含所有实际显示的名称和简介。

分别测试PC／手机搜索、分类、分页、载入／撤销、手势查看、预览、JSON导出和声音接收；没有中文常用名的图案保留原名。
