# 世界编辑器与网页收音

[生命声场国内网页](https://ssstone0903-life-passport.ms.show/)与[GitHub备用网页](https://unstone.github.io/life-passport/)支持PC鼠标／键盘和移动触摸编辑、发送及麦克风接收。接收端先展示已验证预览，应用后通过一个可撤销步骤替换编辑稿；无效、未收齐或已取消的内容始终不替换编辑稿或设备棋盘。实测检查与未完成的实物测试见[部署及验证记录](life-passport-release.zh_CN.md)。

## 交互约定

| 操作 | 行为 |
| --- | --- |
| 画笔／擦除 | 每笔对应一次撤销，插值补齐快速移动跳过的格子；鼠标右键擦除，取消指针恢复本笔。 |
| 缩放／移动 | 1–6倍连续双指缩放与平移；加入第二指时取消未提交笔画，所有手指抬起后才恢复绘制。PC使用Ctrl／Command滚轮、空格拖动；重置视野不改变细胞。 |
| 图鉴 | 519个完整具名图案，支持分类、搜索、缩略图快捷载入与撤销，见[图鉴数据及验证](pattern-catalog.zh_CN.md)。 |
| 图片 | 上传后调整阈值／反相，选择2／3／4代周期并本地计算近似图案；预览真实演化，主动采用后再发送，采用的细胞及设置可一起撤销。 |
| 键盘 | 方向键定位，空格切换，Enter绘制，Delete／Backspace擦除；Ctrl／Command Z及Shift Z撤销／重做。 |
| 清空／替换 | 清空、载入世界码、随机世界和导入均可撤销；保留100步，新修改清除重做记录。 |
| 预览 | 按当前边界／间隔模拟B3/S23；暂停时将当前代作为一个可撤销步骤，取消则返回原图案；预览中禁用发送。 |
| 保存 | 导出／导入含144字节位图、设置和CRC的有限JSON；编辑稿在当前页面，离开前可导出。 |
| 发送 | 精确保留世界码生成的原始棋盘时仍发短包；编辑后发送完整棋盘；编码／播放期间锁定操作，停止会取消待完成编码。 |
| 接收 | 主动开始才申请麦克风权限，显示信号、解码计数和分片进度；停止、切后台、收齐或失败均关闭音轨、音频上下文和Worker。 |
| 应用／放弃 | 收齐后停止收音，单独显示棋盘、细胞数、CRC和设置；主动应用产生一次撤销记录，放弃保持原稿。 |

网页收音需要HTTPS／localhost、WebAssembly、模块Worker和AudioWorklet，使用新版Safari／Chrome。音频图请求48kHz，由浏览器将实际输入重采样至该采样率；AudioWorklet每2048个采样将PCM传给Worker运行固定长度GGWave RX，不保存或上传录音。待处理PCM超过4块时明确停止，避免静默丢弃采样；WAV导入走同一解码与校验流程，限制15MB／120秒／双声道。权限拒绝和不支持的API会明确显示。

## 图片生成自然循环图案

浏览器原生图片解码器读取文件（最多20MB／3600万像素），等比例适配后采样为36×32目标。通过Otsu自动阈值、可调阈值和反相提取前景，透明像素保持背景；原图不上传。简单图标比照片更容易生成可辨识的近似图案。

初始布局根据图片目标放置已验证的独立B3/S23振荡器相位／方向，间隔依据振荡器所有相位的完整包围范围。随后按需加载的Worker使用logic-solver 2.0.1／MiniSat优化重叠的8×8区域：变量覆盖每个相位，约束所有生命规则转换、相邻固定细胞、当前边界及精确周期，并保留最小变化量。目标函数对缺失前景计4、额外细胞计1；每个候选都独立演化复验，必须在指定精确周期回到初始棋盘。显示的匹配度为目标前景与第0代细胞的Dice重合率，接受的可见结果不降低该值。这是有时限的局部优化，不保证全局最优或原图精确还原。

用户选择10／20／40秒时限，每个Worker最多处理4个区域以限制保留的求解器内存；主线程在超时、停止、关闭或切后台时可终止计算，保留独立验证通过的最佳结果。预览持续计算普通生命规则，不在周期边界重置。主动采用才替换编辑稿；关闭或错误均不替换。更换图片、阈值、反相、周期或边界使结果失效。周期信息只用于本地界面，声音发送普通细胞和设置，设备无需增加演化规则。

初始构造模块为CC-BY-SA-3.0图案衍生数据，运行 `node tools/catalog/build_image_modules.mjs` 从固定来源的图鉴生成；来源、相位范围和许可保存在 `assets/patterns/image-modules.json`。应用与求解器的独立许可保存在 `site/public/LICENSES.txt`。

## 完整棋盘扩展：LP1-B1

原世界码／诊断格式与GGWave设置见[声音实验室](acoustic-lab.zh_CN.md)。B1使用LP1此前未启用的类型2和3；旧固件会拒绝B1，并继续接收世界码，手绘棋盘需要升级设备固件。

| 字节 | B1含义 |
| --- | --- |
| 0–2 | ASCII `LP`，版本1。 |
| 3 | 低2位：分片=2、头部=3；第2位环绕，第3–4位速度索引 `{125,200,500,1000}`，第5–6位编码，第7位零。 |
| 4 | 头部为255；分片为从0开始的编号，最大28。 |
| 5–6 | 小端随机16位传输编号。 |
| 7–11，头部 | 编码长度1字节，范围1–144；随后为完整144字节位图CRC32，小端。 |
| 7–11，分片 | 5字节编码内容，末片剩余字节必须补零。 |
| 12–15 | 前12字节的IEEE CRC32，小端。 |

所有分片重复头部的设置，编号和设置必须匹配；拒绝越界编号、非零尾部填充以及内容不同的重复分片。重复相同头部保留已收片，可跨循环补齐；不同传输编号开始新事务，同一编号的元数据／内容冲突则清空事务并报告拒绝。没有头部的分片被忽略，循环播放可提供下一轮头部；未完成接收在15秒无有效匹配帧或总计120秒后过期。解压和整盘CRC全部通过才生成种子。CRC不认证身份，16位编号用于区分事务，不提供完整性保证。

| 编码 | 精确表示 |
| --- | --- |
| 0 | 144字节原始位图，逐行、低位优先。 |
| 1 | 3字节小端裁剪头部：`x | y<<6 | (width-1)<<11 | (height-1)<<17`，高2位零；后接裁剪区域逐行位图，校验边界及填充。 |
| 2 | 活细胞坐标：1字节数量，最多103；随后为严格递增的11位格子索引，低位优先打包。 |
| 3 | 相同格式的死细胞坐标，其他格子均为活细胞。 |

选择最短编码，原始位图保证上限。小闪烁器可用头部加1片；不可压缩的整盘需要头部加29片。按当前实测波形时长，含0.35秒间隔，一轮六音约1.724–25.86秒，双音约3.516–52.74秒；丢片和重播会延长时间。完整棋盘使用相同编号和内容循环，最长180秒，短包循环仍最长60秒；每次主动发送生成新编号。

## 验证与手动验收

实施按模型／协议→C与浏览器组装→设备任务→编辑／收音界面进行。主机测试逐位比较JavaScript和生产C棋盘，覆盖缺片、乱序、重复、冲突、错误编码／填充／CRC、过期和最大边界；真实WASM声音交由浏览器与原生接收器解码，覆盖完整多包棋盘。界面分别验证桌面与移动尺寸、鼠标／键盘／触摸路径，实物时序和手机声学另行记录。

| 编号 | 操作与预期 |
| --- | --- |
| TC15 | PC清空后拖画一条线、擦除、撤销／重做；一次撤销对应一笔，棋盘聚焦时键盘可编辑。 |
| TC16 | 手机绘制，再双指缩放／平移，抬起一指后继续移动，再全部抬起；手势不绘制，也不产生撤销记录。 |
| TC17 | 预览后取消，再预览并暂停；取消保留原图案，暂停采用当前代，撤销恢复；导出／导入CRC一致。 |
| TC18 | 一台PC／手机发送手绘棋盘，另一台收音，对照图案／细胞数／CRC；放弃保留原稿，应用可撤销。 |
| TC19 | 循环中途开始接收，中断后继续；只对完整棋盘预览，保留匹配的已收片，停止／后台释放麦克风。 |
| TC20 | 向升级后的AI Passport发送手绘棋盘，对照图案／CRC，实体应用／取消；世界码仍可接收。 |
| TC21 | PC和手机搜索／筛选图鉴，载入、预览、撤销并发送；完整图案适配棋盘，不裁剪细胞。 |
| TC22 | 检查精简后的设备工具／说明菜单，无机上图鉴、细胞编辑或操作说明页。 |
| TC23 | PC和手机上传简单图标，分别计算2／3／4代周期，检查近似轮廓及循环预览，采用后撤销／重做，细胞和设置一起恢复。 |
| TC24 | 优化期间停止、关闭／切后台或改变阈值／周期；只有已验证结果可采用，取消的任务不能替换编辑稿。发送已采用的图片结果，并对照接收端CRC。 |

使用ESP-IDF 5.5.3和Node 22.22.3执行 `./tools/validate.sh`。分别测试浏览器权限拒绝／允许、部署子路径下Worker／Worklet加载、权限或解码器加载中途停止；区分模拟／文件解码与真实麦克风、设备声学结果。
